# 💻 Algoritmos e Programação

Repositório dedicado ao armazenamento das minhas resoluções práticas da disciplina de Algoritmos e Programação do curso de Análise e Desenvolvimento de Sistemas (ADS).

## 🛠️ Tecnologias e Ferramentas

* **Linguagem Base:** Python 3.13 🐍
* **Ambiente de Desenvolvimento:** VS Code 🚀
* **Documentação:** Markdown `(.md)` 📑

## 📂 Organização do Repositório

O projeto é dividido em dois pilares fundamentais para garantir uma consulta rápida e um histórico acadêmico limpo:

* 📝 **`exercicios/`**: Listas de exercícios oficiais aplicadas durante o semestre.
* 🎓 **`avaliacoes/`**: Arquivo histórico de provas oficiais e resoluções de semestres anteriores.

## 🗺️ Guia de Navegação

* 🏃‍♂️ [Exercícios Práticos e Listas](./exercicios/)
* 🗄️ [Histórico de Avaliações](./avaliacoes/)

## 🎯 Competências Desenvolvidas

- **Lógica de programação:** decomposição de problemas e pensamento computacional
- **Fundamentos de Python:** variáveis, tipos de dados, operadores e entrada/saída
- **Estruturas de controle:** condicionais e laços de repetição
- **Modularização:** criação e reaproveitamento de funções
- **Estruturas de dados nativas:** listas, tuplas, dicionários e strings
- **Depuração e testes:** identificação de erros e validação de resultados
